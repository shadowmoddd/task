# ML Research Assistant

Локальный LLM-ассистент для исследователя. Принимает запрос пользователя (например, *«Какие тенденции в развитии LLM имеют место в 2025-2026 году?»*) и формирует развёрнутый исследовательский отчёт с использованием веб-поиска, полностью работая на локальной инфраструктуре — без передачи данных на внешние серверы и без проприетарных API.

Построен на базе [local-deep-researcher](https://github.com/langchain-ai/local-deep-researcher) (LangGraph + Ollama) с веб-интерфейсом на Streamlit.

## Возможности

- Итеративное исследование: система генерирует поисковый запрос, ищет в интернете, суммаризирует результаты, находит пробелы в знаниях и уточняет запрос — цикл повторяется заданное число раз.
- Полностью локальная LLM через Ollama (по умолчанию `llama3.1:8b`, ≤ 32 млрд параметров).
- Локальный веб-поиск через SearXNG (без ключей API) либо DuckDuckGo как запасной вариант.
- Готовый отчёт с указанием источников, экспорт в `.md` и `.html`.
- Настройка глубины исследования, модели и поисковика прямо в интерфейсе.

## Требования

- Python 3.11+
- [Ollama](https://ollama.com) — для локального запуска LLM
- (опционально, но рекомендуется) [Docker](https://www.docker.com) — для локального поисковика SearXNG

## Установка

1. Клонируйте или скачайте репозиторий и перейдите в его папку:
   ```bash
   cd local-deep-researcher
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate        # Windows
   source .venv/bin/activate     # macOS / Linux
   ```

3. Установите проект в editable-режиме и дополнительные зависимости для веб-интерфейса:
   ```bash
   pip install -e .
   pip install streamlit markdown2
   ```

4. Скачайте локальную модель через Ollama:
   ```bash
   ollama pull llama3.1:8b
   ```

5. (Рекомендуется) Поднимите локальный поисковик SearXNG:
   ```bash
   docker run -d -p 8888:8080 searxng/searxng
   ```
   Проверьте, что он работает: откройте `http://localhost:8888` в браузере.

   Если Docker недоступен — можно использовать поисковик DuckDuckGo (без установки), выбрав его в интерфейсе.

## Запуск

1. Убедитесь, что Ollama запущена (обычно запускается автоматически после установки; при необходимости — `ollama serve`).

2. Запустите веб-интерфейс:
   ```bash
   .venv\Scripts\python.exe -m streamlit run app.py    # Windows
   streamlit run app.py                                 # macOS / Linux
   ```

3. Откроется браузер на `http://localhost:8501`.

## Использование

1. В боковой панели выберите модель Ollama, поисковик (`searxng` или `duckduckgo`) и глубину исследования (число итераций поиска — больше циклов даёт более полный отчёт, но увеличивает время выполнения).
2. Введите исследовательский запрос в текстовое поле.
3. Нажмите **«Исследовать»** и дождитесь завершения (обычно от нескольких минут до десятков минут, в зависимости от модели, глубины и производительности GPU/CPU).
4. Готовый отчёт отобразится на странице. Его можно скачать в формате `.md` или `.html` кнопками под отчётом. Файлы также сохраняются локально в папке `reports/`.

## Структура проекта

```
local-deep-researcher/
├── src/ollama_deep_researcher/   # ядро системы (граф LangGraph, промпты, поиск)
│   ├── graph.py                  # основной пайплайн исследования
│   ├── configuration.py          # настройки LLM и поисковика
│   ├── state.py                  # состояние графа (запрос, отчёт, источники)
│   ├── prompts.py                # промпты для генерации запросов и суммаризации
│   └── utils.py                  # функции поиска и форматирования
├── app.py                        # веб-интерфейс (Streamlit)
├── reports/                      # сохранённые отчёты (создаётся автоматически)
└── README.md
```

## Ограничения

- Размер используемой LLM не превышает 32 млрд параметров.
- Система не использует проприетарные сервисы/API — только локально развёрнутые модели и открытый веб-поиск.
- Ожидаемое время формирования ответа не превышает 2 часов на один запрос при работе на GPU.
